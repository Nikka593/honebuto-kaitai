# 骨太解体新書

骨太の方針2026（経済財政運営と改革の基本方針2026）と日本成長戦略の「17の戦略分野」を、経済の予備知識がなくても人に説明し、正しく批評できるようになることを目指した学習サイトです。

公開ページ: https://nikka593.github.io/honebuto-kaitai/

## 方針

- 中立：特定の政党や立場を応援・批判するためのサイトではありません。政府の方針と、それへの賛否の両方を載せます。
- 一次資料が先：数字は政府の本文・統計などの一次資料と照らし合わせてから載せます。報道の数字は「報道による」と明記します。
- 事実と整理を分ける：グループ分け、暮らしの例、たとえ話はサイトの整理として明記します。
- 毎週見直す：週に1回、新しい決定や数字を確かめて更新し、ページ下部の更新履歴に残します。

## 誤りの報告

誤りや古い情報に気づいたら、このリポジトリの Issues に書き込んでください。根拠となる資料のURLがあると確認が早くなります。
