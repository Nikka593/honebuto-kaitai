# 写真・画像の置き場所とルール

サイトに写真を載せるときは、このフォルダに画像を置き、`index.html` の `<figure class="photo">` と同じ形で追加します。

## 使ってよい画像（どれも出典の記載が必要）
- **当サイトが作った図やイラスト**：「イラスト：当サイト作成」と書く。
- **首相官邸サイトの写真**：コピーライトポリシーでは、特に表示がない限り「公共データ利用規約（第1.0版）（PDL1.0）」に従って利用できる。出典は官邸が示す書き方に従い、該当ページのURLも書く。写真ごとに別の表示があれば、そちらが優先される。使う前に毎回、最新のポリシーを確認する。
- **Wikimedia Commons などで、CC0・CC BY・CC BY-SA と明記された写真**：作者名、ライセンス名、元のページへのリンクを書く。
- **依頼者が自分で撮った写真**：人物が写っているときは、顔がわからないようにするなど配慮する。

## 使わない画像
- 新聞社・通信社・テレビ局の写真や映像の切り抜き（許可がない限り使えない）。
- 衆議院・参議院の審議中継の映像や、そのスクリーンショット。これらはリンクで案内する。
- 出典やライセンスがわからない画像。

## 中立のためのルール
- 特定の政党や政治家の印象をよく見せたり、悪く見せたりする写真を選ばない（表情、角度、場面の切り取り方に気をつける）。
- 与党側の写真を載せるなら、質問する側（野党側）の写真も同じ大きさで並べる。並べられないときは、議事堂の外観や議場の全景など、人物が主役でない写真にする。
- 説明文（キャプション）には、日付・場所・何の場面かという事実だけを書く。「激論」「紛糾」などの評価は、報道の表現ならその報道名を添える。

## 形式
- 横1200px程度、WebP または JPEG で、1枚200KB以下を目安にする。
- `alt`（画像の説明文）を必ず書く。`loading="lazy"`、`width`/`height` を付ける。

## 追加の例
```html
<figure class="photo">
  <img src="images/2026-10-13-yosan-iinkai.webp" alt="衆議院予算委員会の様子（2026年10月13日）" width="1200" height="750" loading="lazy">
  <figcaption><b>衆議院予算委員会</b>　2026年10月13日<span class="credit">出典：首相官邸ホームページ（URL）</span></figcaption>
</figure>
```

## 注意（作業環境について）
自動の週次更新を行う環境では、ネットワークの設定によって官邸や Wikimedia のサイトにアクセスできないことがある。写真の追加は、アクセスできるときか、依頼者が画像を用意したときに行う。
